# Daily 5-minute routine (Admin: /#admin)
1. **Health:** `/healthz` should return ok, with vision set to `xai`.
2. **Review queue (2 min):** approve what looks normal, and reject reports where the photo disagrees with the size or shows no pump.
3. **Daily question:** check that tomorrow's question is scheduled. Approve or reject paid sponsored questions; personal-data questions are already blocked.
4. **Leads:** reply to new quote requests the same day.
5. **Money:** check the pot vs the goal, and the kill switch if anything looks wrong.

# Weekly (Sunday evening, Facebook Live, about 10 min)
1. Before going live: open `#live` and press **Publish commitment**. Post the hash in the FB event comments.
2. On air: last week's winner presses **PICK**. Read out the masked winner, then link `#audit`.
3. Contact the winner from the Outbox email and send the prize. Note the prize value for 1099s.
4. Set next week's prize options if needed. The member vote decides.

Click **Distribute last month's member share**. Download a backup. Check the 1099 watch.
